# Code review fixture

Use this skill as inert reference material when testing catalog lookup and supporting-file
retrieval. It does not execute commands or modify files.

## Procedure

1. Read the review checklist.
2. Apply the severity scale to each finding.
3. Return the findings as ordinary text.
